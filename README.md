This is all of the relevant information and code pertaining to getting quanitfiable data from the images.

Both the kymograph (biochemical data) and PIV (mechanical data) can be computed here.

Start with the 'Image Analysis Code Protocall.ipynb' first to see what it is you need to change.
ALWAYS MAKE A COPY, DO NOT DIRECTLY EDIT!!!!

Download the code and alter what needs to be altered.

Once you have run the code on your own data, check out the plotting code to see how you can visualize your results! I have added a 2 example data sets to practice the plotting stuff. You can pull them to your desktop and work directly in the notebook.

Good luck!
